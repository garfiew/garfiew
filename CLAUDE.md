# CLAUDE.md

This file auto-loads for every Claude Code / Cowork session opened in this project. Read it first, then `TASKS.md` for current status.

## What This Project Is

A learning workspace for a marketing consultant/freelancer building professional content strategy and paid media skills, using one real client brief as the running case study — not hypothetical examples.

See `MISSION.md` for the full learning goal and target audience context.

## The Case Study

**Skinless Foundation** — "No More Make Up, Skinless Foundation is New Skin"
50,000 THB / 1 month, Meta + TikTok, no website (Meta Shop / Shopee / Lazada only).

The finished strategy lives in `CAMPAIGN-PRD.md` — content pillars, platform strategy, budget allocation, 4-week calendar, KPIs. Treat it as the canonical output of the course, not a draft to redo.

## File Map

- `MISSION.md` — why the user is learning this, what success looks like, learning style preferences
- `NOTES.md` — accumulated user preferences and teaching approach notes (read before teaching)
- `RESOURCES.md` — reference links used across lessons
- `CAMPAIGN-PRD.md` — the applied Skinless Foundation strategy (source of truth for the case)
- `TASKS.md` — live snapshot of course progress and next actions; re-read this each session, it changes between sessions
- `learning-records/000N-*.md` — one file per teaching session: what was covered, key insights, zone of proximal development for the next lesson
- `lessons/000N-*.html` — interactive lesson content, styled via `assets/style.css`

## Working Conventions

- Teach using the Skinless Foundation case for every lesson — never switch to a hypothetical example (see `NOTES.md`)
- One lesson = one strategic decision the user needs to make for this client
- After each teaching session, append a new `learning-records/000N-*.md` file (don't edit prior ones) capturing what was covered, key insights, and the zone of proximal development for next time
- Confirm before drafting new strategy content into `CAMPAIGN-PRD.md` — it's treated as a finished deliverable, not a scratchpad
- User teaches back in Thai but reads English content — lesson material stays in English unless asked otherwise
