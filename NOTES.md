# Notes

## User Preferences
- Learns best with real client cases, not hypothetical examples
- Wants to apply each lesson immediately to the Skinless Foundation project
- Step-by-step pacing preferred
- Mix of Thai context and English marketing terminology

## Context
- Has a real client delivering a makeup/skincare campaign
- No website — all conversion happens on Meta Shop, Shopee, Lazada
- Budget is tight: 50,000 THB for Meta + TikTok combined
- Audience spans mainstream (women 20–35) + LGBTQ+ makeup community

## Teaching Approach
- Use the Skinless Foundation case as the running example for ALL lessons
- Each lesson = one strategic decision they need to make for this client
- Quiz questions should use Thai market context where possible
